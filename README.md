# Quim

Assistente conversacional para amadurecer uma **reescrita contemporânea de "Teoria do Medalhão"**, de Machado de Assis, na disciplina Introdução ao Direito 1 da Faculdade de Direito da UnB.

Quim não escreve a reescrita no lugar do estudante: conversa com o texto até ele ganhar maturidade real, usando um critério de cinco sinais de maturidade e perguntas hipercomplexas quando o rascunho já chega sofisticado (sinal de uso de um modelo forte por trás).

## Como usar

Quim é um **prompt portátil**: um texto que se cola como primeira mensagem em qualquer assistente de IA gratuito (Claude, ChatGPT etc.), sem instalar nada.

1. Copie o conteúdo de [`prompt_portatil.md`](prompt_portatil.md).
2. Cole como primeira mensagem numa conversa nova. Se já tiver um rascunho, cole junto.
3. Converse normalmente até Quim encerrar e escrever a avaliação.
4. Copie a avaliação (não o texto reescrito, não a conversa inteira) e entregue.

`index.html` é a página publicada com o botão de copiar (a mesma fonte também vive como [Claude Artifact](https://claude.ai/code/artifact/fc8e116b-428e-450e-b5e4-413bf76fdf9f)).
